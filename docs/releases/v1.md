# v1

PCL 下载功能恢复工具，适用于 PCL 2.99.0.0。

- 原生 WPF 单文件程序，沿用 TRM UI 浅色样式。
- 恢复自动安装、加载器选择、本地和在线整合包安装入口。
- 自动备份，支持一键还原。

下载 `PCL-Helper-v1.exe`，退出 PCL，选择其 exe，点击“恢复下载”，然后重新打开 PCL。

运行环境：Windows / .NET Framework 4.8。第三方独立工具，与 PCL 官方无关联。

已验证真实下载页初始化、全部 6 个修改方法和备份还原；尚未完成所有游戏版本、加载器和整合包的端到端安装测试。
