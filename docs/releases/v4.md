# v4

修复 PCL 在原路径更新后，残留旧备份导致无法再次恢复下载的问题。不同原文件的旧备份和记录会先保存在历史目录，再建立当前版本备份；未带 Helper 修补标记的文件无需还原，不会被旧备份覆盖。

支持 PCL 2.99.0.0 / 2.99.0.1。已使用实际发布的 v1、v2、v3 验证旧版修补还原、同路径更新、降级、重复操作、历史备份保留，并分别回归新旧两个 PCL 版本的原生 GUI。v4 为独立发布，旧版本标签与附件保留。

保留 PCL 原图标，已核对新旧版本全部 10 种图标尺寸及原生资源逐字节一致。

旧 PCL 更新前先点击“还原所选”，更新完成后点击“恢复所选”，均使用 v4 即可。请保留 EXE 旁的备份、记录和历史目录。
