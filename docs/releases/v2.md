# v2

新增 HMCL 支持、快速扫描、多程序选择与批量操作，使用图灵镜 LOGO 和原生 WPF 界面。

- 支持 PCL 2.99.0.0 下载与整合包安装功能恢复，支持原文件备份和精确还原。
- HMCL 启动时附加台北时区参数，保留已有 JVM 选项，不修改程序文件或系统时区。
- 快速扫描常用目录，支持手动添加、拖入和指定目录扫描。
- 多程序列表与单按钮全选切换，恢复、还原、检查和启动统一处理勾选项目。
- 新增图灵镜软件图标、官网和社媒入口、离线 QQ 社群二维码。

实际验证：HMCL 1.12.2 / 1.20.1 下载、安装与支持库修复通过；PCL 的 Modrinth 公开整合包、CurseForge 格式样本安装及原版文件补全通过。PCL 的补全不会恢复缺失模组。HMCL 验证使用官方 CI `3.17.dev-8827fd0`；未覆盖所有版本、全部整合包或进入游戏。

下载 `PCL-Helper-v2.exe` 即可运行，校验文件为 `SHA256SUMS-v2.txt`。Windows 需要 .NET Framework 4.8。v1 标签和附件保留原样，本版本单独发布为 v2。
