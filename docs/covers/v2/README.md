# v2 双启动器封面

使用内置 image_gen 生成，参考 PCL 和 HMCL 官方仓库中的 Logo。三版采用浅蓝与白色方块场景，顶部并排双 Logo，中部主标题，底部说明文案。

Logo 参考来源：

- PCL：https://github.com/Meloong-Git/PCL/blob/main/Plain%20Craft%20Launcher%202/Images/icon.ico

生成说明：分别生成一张独立横版 16:9、横版 4:3 和竖版 9:16 宣传封面。沿用两款启动器的 Logo 形象与字母，保持双 Logo 上方并排。以大号深色中文无衬线字体显示“支援未来！”和“在沦陷之前。”，完整显示用户说明文案。背景为明亮浅蓝、白色的 Minecraft 风格方块地形与天空，保证文字对比度和边缘留白。三版按画幅重新排版，不拼接成一张图，不增加其他文案。
